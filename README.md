# Tic-Tac-Toe — React + TypeScript

A simple Tic-Tac-Toe game built with React, TypeScript, and Vite.

## Features

- 3x3 board with click-to-play
- Win and draw detection, with the winning line highlighted
- Move history with "jump to move"
- Restart game

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
